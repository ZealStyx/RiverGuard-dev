What drives this number

Sensitivity, not SHAP: each input is pushed to the ends of its range with everything else fixed, and the change in probability is shown. The sign tells you which direction raises risk.

3 · Seven-day outlook

In the final build a weather API fills these seven days automatically. Here you set them by hand: each day's rain feeds the next day's antecedent totals and soil moisture, so the outlook accumulates the way a real wet spell does.
