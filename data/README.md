# RiverGuard — NCR Daily Dataset v2

Generated by `data/generate_dataset.py` (Python 3, seed 42, deterministic).
Covers **2016-01-01 → 2026-11-14** (3,971 days) for four NCR cities:
Quezon City, Marikina, Manila, Pasig → **15,884 rows**.

> **Read this before reporting any model metric.** The dataset is *partly real,
> partly modelled*. The "Reliability" table below states exactly which column is which.
> It is built to unblock Phase 1/2 engineering (schema, features, pipeline, baselines)
> and is **not** a substitute for gauge observations or operational flood warnings.

**Preview:** open `data/dataset_preview.html` in a browser (self-contained, no internet
needed) for interactive charts of everything below.

## Reliability — what is real and what is modelled

| Column | Status | Method |
|---|---|---|
| `Rainfall_mm` before 2025-11-15 | **Synthetic, calibrated** | Markov wet/dry + Gamma intensity, monthly totals rescaled to PAGASA 1991–2020 normals × U(0.85, 1.15); 60% shared NCR synoptic factor |
| `Rainfall_mm` 2025-11-15 → 2026-11-14 | **Real** | ERA5 reanalysis daily totals per city (Open-Meteo), stored verbatim in `era5_recent_rainfall.py` — 1,460 rows, `RainSource = ERA5-reanalysis` |
| `Rainfall_mm` 2020-11-11/12 | **Real** | ERA5 Manila (44.3 / 178.4 mm); other cities scaled — `RainSource = ERA5-anchor` |
| `Tmax_C`, `Tmin_C`, `ET0_mm` | **Synthetic, calibrated** | Port Area monthly normals + noise |
| `SoilMoisture_pct` | **Derived** | Bucket: `SM_t = clip(SM_{t-1} + Rain − ET0 − 0.08·SM_{t-1}, 5, 95)` |
| `AntecedentRain_3/7/30d_mm` | **Derived** | Rolling sums shifted 1 day (no target leakage) |
| `WaterLevel_m` | **Derived, not gauge data** | `WL = base + 0.006·Ant7 + 0.018·Rain + 0.004·Ant3 + ((Alarm3−Alarm1)/40000)·Rain² + N(0,0.10)`; datum calibrated so Alarm 1 is exceeded ~2% of days |
| `FloodOccurrence` | **Rule-based proxy** | `WL ≥ Alarm1 OR (Rain ≥ 100 & Ant7 ≥ 150) OR Ant3 ≥ 250` |
| `RiskLevel` | **Derived** | WL vs alarm bands + same-day rainfall |

**Checked (see `Quality_Checks`):** 15,884 rows, no gaps, no duplicates, no missing
values; flood prevalence **2.06%** (328 positives); per-city positives 78–86 (no city
dominates); annual rainfall 1,855–2,805 mm across cities (PAGASA normals: 2,044–2,574);
Marikina WL 12.7–20.2 m against alarms 15/16/18 (Ulysses peak 20.2 m, matching the
real 2020 / Carina 2024 range); Ulysses is the dataset maximum.

## Train / validation / test

`Split` column is assigned **chronologically** — never shuffle across these:

| Split | Window | Rows | Flood positives |
|---|---|---|---|
| train | 2016-01-01 → 2023-12-31 | 11,688 | 256 |
| validation | 2024-01-01 → 2024-12-31 | 1,464 | 19 |
| test | 2025-01-01 → 2026-11-14 | 2,732 | 53 |

With 2% prevalence, report **precision / recall / F1 / PR-AUC / Brier + calibration**,
not accuracy. Keep 2020-11 (Ulysses) inside train and consider a leave-one-event-out
check as an extra robustness test.

## Known limitations

- City-level resolution only; no barangay-level cross-correlation, no tidal backwater
  for Pasig/Napindan, no dam operation (Wawa, Angat, Ipo, La Mesa).
- Water level is a rainfall-driven proxy: it cannot reproduce surge timing or backwater
  effects, so lead-time studies on this data are indicative only.
- Rainfall changes provenance mid-series (synthetic → real ERA5 at 2025-11-15). Use
  `RainSource` if you need a homogeneous training set; never let a model learn the
  provenance boundary as a feature.
- Synthetic storm events (2018-08-06, 2019-09-14) are deliberate calibration
  stress-tests flagged in `Notes`; they are not observations.
- Pasig alarm thresholds (12.0 / 12.5 / 13.0 m) come from a secondary source and are
  marked "verify" in `Thresholds`.

## Units, timezone, licensing

- **Units:** rainfall mm/day, water level m (gauge datum per river; not a common
  vertical datum), soil moisture %, temperature °C, ET0 mm/day.
- **Timezone:** all dates are Asia/Manila (UTC+8) local calendar days. For Convex
  `sensorReadings.observedAt`, use 00:00 Asia/Manila for each row.
- **Licensing:** no third-party raw data is redistributed. PAGASA normals/thresholds
  are cited facts; ERA5 values are re-derived from the Open-Meteo API (Copernicus
  ERA5, CC-BY-4.0). The synthetic table is generated by this repository.

## Upgrade path to operational grade (Phase 1 exit criteria)

1. Replace `Rainfall_mm` with PAGASA AWS / EFCOS gauge series per station.
2. Replace `WaterLevel_m` with PAGASA FFWS / EFCOS telemetry at Sto. Niño (Marikina),
   Rosario and Pandacan (Pasig).
3. Replace `FloodOccurrence` with LGU-validated event records (Marikina MDRRMO,
   Pasig DRRMO, QC DRRMO) plus NDRRMC/validated reports.
4. Keep these column names and the sheet layout so the ingest path in
   `convex/schema.ts` (`stations`, `sensorReadings`) needs no change.
